# Blackjack en Python

Mi primer proyecto personal en Python.

## Descripción

Juego de Blackjack desarrollado en Python. Como proyecto para materia de 
Ingeniería en Sistemas de Información

## Características

- Mazo de 52 cartas
- Reparto de cartas sin repetición
- Turno del jugador
- Turno de la banca
- Reglas básicas de Blackjack

## Tecnologías

- Python
