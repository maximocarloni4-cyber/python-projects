# 🎬 Gestor de Películas

Un script interactivo en Python desarrollado para practicar el manejo de estructuras de datos, manipulación de listas y lógica de filtrado/búsqueda.

## 🚀 Características
- **Carga de datos:** Permite agregar películas con sus respectivos atributos (título, género, año, calificación).
- **Consultas y filtros:** Búsqueda de títulos específicos y filtrado por género o año.
- **Formato de salida:** Presentación limpia de la información en consola.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Python 3.x
- **Conceptos aplicados:** Listas, Diccionarios/Tuplas, Bucles (`for`/`while`), Condicionales.

## 📋 Cómo ejecutarlo
1. Clona este repositorio o descarga el archivo `.py`.
2. Ejecuta el script en tu terminal:
   ```bash
   python peliculas.py
